RoudaMix Portable — Windows x64
==============================

完整解壓至本機可寫入的資料夾，執行 RoudaMix.exe。
portable.flag 啟用 portable 模式；設定、session 及瀏覽器資料位於 data 資料夾。
更新版本時請保留自己的 data 資料夾。

需要 Windows 10/11 x64 與 Microsoft Edge WebView2 Evergreen Runtime。
本 ZIP 不附 WebView2；如未安裝，請使用 RoudaMix 安裝版，或從 Microsoft 官方頁面安裝：
https://developer.microsoft.com/microsoft-edge/webview2/
WebView2 為 Microsoft 提供的獨立平台元件，依其授權及隱私條款使用。

使用 ASIO 輸出須先安裝硬體的 ASIO 驅動；VST3 外掛由使用者自行安裝。
啟用「登入時自動啟動」會寫入 Windows 啟動登錄，移動程式前請先停用。
目前未使用 Authenticode 簽章，Windows 可能顯示未知發行者提示。
